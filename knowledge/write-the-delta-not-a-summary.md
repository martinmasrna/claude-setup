name: write-the-delta-not-a-summary
description: "Never summarise a source already in the repo — record only what changes a decision, and point at the source"
metadata:
  type: feedback
---

When a source document exists in the repo (a transcript, a study, a scrape), never write a summary of it into another file. Record only the parts that change a decision — a pointer plus the deltas, in as few lines as possible. The précis is guaranteed to drift from the source and nobody reads two accounts of the same thing. Test per line before adding to any doc: what would a reader *do differently* because of it? This is Martin's most-repeated correction ("we'll never get anything done because we'll get lost reading the Bible that is your documentation") — a 46-minute transcript's notes were five lines, not 700 words of bullets.
