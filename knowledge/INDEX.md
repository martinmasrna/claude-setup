# User-level knowledge index

One line per fact; read a body only when its line is relevant.

## Working method
- [Epistemic discipline](epistemic-discipline.md) — tag unvalidated guesses; set thresholds before testing; read the producing code before contradicting a number
- [Write the delta, not a summary](write-the-delta-not-a-summary.md) — never summarise a source already in the repo; record only what changes a decision
- [Two passes, then show it](two-passes-then-show.md) — two self-directed polish passes max, then ship for his judgement
- [Fix the argument before the craft](fix-the-argument-before-the-craft.md) — on rejection, ask whether the thing should exist before improving how it looks

## Taste
- [Writing taste](writing-taste.md) — most sentences simply communicate; every copy element leads with reader self-interest
- [Design taste](design-taste.md) — cut ~80% of labels; one goal per surface; scannable as a graphic before readable as text
- [Figures](figures.md) — show mechanism, not data-in-a-grid; judge rendered at real reading size, by eye

## Environment
- [Machine environment](machine-environment.md) — python3 not python; Homebrew broken, use ~/.local/bin; codex CLI available; small viewport (~1280x630)
