One root rule — don't present unverified inference as fact — learned in three costumes (Ghostwriting sessions, 2026-08):

**Tag your own inferences.** Audience-psychology guesses stated with the confidence of analysis were flatly wrong when checked against real data (719 harvested X reactions). A subagent's digest is a map for finding claims, never the authority for them: a client piece drafted from a digest propagated a factual misread of the paper. State epistemic status inline ("unvalidated — checkable via a reply harvest") and prefer checking cheaply over asserting. Claims that cross between sessions acquire false independence — recompute a peer's number before recording it, and label your own as *computed* or *eyeballed*.

**Set the threshold before looking.** A loose comparison bar (0.04 on groups of ten) manufactured six false "reversals"; a defensible bar (≥15 points, n≥15) returned zero. Decide what counts as a real difference and what minimum group size makes it meaningful before running the test. If a result looks like a finding, re-run at the stricter bar before telling anyone — especially before telling someone their work is wrong. Report the test, not just the verdict.

**Read the producing script.** Recomputing a repo number and getting something different locates a *disagreement*, not an error. I contradicted a committed count (49 vs 42) with a guessed provenance story; reading the fifteen lines that produced it showed two different counting rules in play — neither was mine. Before calling a committed number wrong, find the code that emitted it and reproduce the number under its own rule first.
